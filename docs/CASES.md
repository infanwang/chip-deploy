## 案例 2：PicoRV32 RISC-V 核（v1.0.0 → v1.2.0）

**目标**：验证万门级 SoC 核完整签核，并压榨时序。

**频率演进**：

| 周期 | 频率 | Setup(SS) | Hold(FF) | 面积 | 功耗 |
| :--- | ---: | ---: | ---: | ---: | ---: |
| 30 ns | 33 MHz | +8.78 ns | +0.128 ns | 176,307 µm² | 7.87 mW |
| 25 ns | 40 MHz | +3.91 ns | +0.134 ns | 176,307 µm² | 9.31 mW |
| **22 ns** | **45.45 MHz** | **+0.912 ns** | **+0.134 ns** | **176,307 µm²** | **10.58 mW** |

**关键成就**：频率 +36.5%，**面积不变**。

**工程判断**：45 MHz 是 PicoRV32 在 SKY130 的实用上限（Setup 裕量仅 4%）。

**学习点**：SDC 约束、CTS 优化、时序裕量分析。

## 案例 3：PicoRV32 SoC（v1.3.0 → v1.4.0）

**目标**：集成 5 个外设，构成完整 SoC，并验证所有功能。

**架构**：

    PicoRV32 @ 40 MHz
        │
    Wishbone 总线
        │
    ┌────┬────┬─────┬────┐
    ROM Timer GPIO UART SPI

**外设地址映射**：

| 外设 | 基地址 | 功能 |
| :--- | :--- | :--- |
| ROM | 0x00000000 | 256 条指令存储 |
| Timer | 0x10000000 | 定时器 + 中断 |
| GPIO | 0x20000000 | 32 位 IO |
| UART TX | 0x30000000 | 串口发送（~100 kbaud）|
| SPI Master | 0x40000000 | SPI 主机 |

**综合结果**：

| 指标 | 数值 |
| :--- | ---: |
| 标准单元 | 15,002 |
| 面积 | 221,653 µm² |
| 功耗 | 12.72 mW |
| 频率 | 40 MHz（25 ns）|
| Setup 裕量（SS）| +2.767 ns |
| Hold 裕量（FF）| +0.122 ns |
| DRC / LVS / Antenna | 全通过 |
| 运行时长 | 16 分 27 秒 |

**功能验证**：

| 外设 | 验证方法 | 结果 |
| :--- | :--- | :--- |
| GPIO | 递增计数 | 0x0 → 0x2c（v1.3.1）|
| Timer | IRQ 周期性触发 | 78 次（v1.4.0）|
| UART TX | 字符序列输出 | 41 字符（B, E, H, K, ...）（v1.4.0）|

**验证命令**：

    iverilog -o sim_soc \
        rtl/picorv32.v rtl/soc_top.v rtl/rom.v \
        rtl/timer.v rtl/gpio.v rtl/uart_tx.v rtl/spi_master.v \
        tb/tb_soc.v
    vvp sim_soc

**学习点**：
- Wishbone 风格总线地址解码
- Timer 单周期 IRQ 脉冲实现
- UART TX 时序验证
- RISC-V 机器码生成（Python 脚本）
- 跳转偏移量计算（手工编码易错）
